# vibe-tools
選擇障礙午餐扭蛋機
1. 專案概述

  專案名稱：午餐扭蛋機 (Lunch Gacha Machine)

  專案目標：打造一個兼具趣味性與實用性的單頁應用程式（SPA），幫助有「選擇障礙」的人們，透過互動式的扭蛋動畫，快速地決定當天的午餐。
  
  目標裝置：響應式網頁設計（RWD），支援手機與桌上型電腦瀏覽。

3. 技術規格 (Technical Stack)
  核心語言：純 HTML5, CSS3, Vanilla JavaScript（不依賴任何外部框架如 React/Vue）。

  架構：三者整合於單一 index.html 檔案中，便於輕量化執行與分享。
  
  部署方式：GitHub Pages 靜態網頁託管。

4.視覺與版面設計 (UI Design)
  
  整體風格：活潑、可愛、明亮。
  
  色彩計畫：主背景使用柔和的粉色（#ffd1dc），按鈕與扭蛋機主體使用亮眼的櫻桃紅（#ff4757），搭配暖色調的木質小熊（#8b5a2b）。
  
  畫面佈局 (由上到下)：
    
    大標題：「今天吃什麼？🍱」。
    
    主視覺區：畫面中央為 CSS 繪製的扭蛋機（含透明視窗、彩色迷你扭蛋、旋鈕與出口）。左下角配置一隻 CSS 繪製的胖胖小熊作為陪伴角色。
    
    主操作區：大面積的「轉動扭蛋！」互動按鈕。
    
    清單管理區：半透明白色面板，上方以標籤（Tag）形式顯示目前所有的午餐選項；下方提供文字輸入框與按鈕供使用者新增選項。
    
    結果顯示區：隱藏式的全螢幕半透明黑底覆蓋層（Overlay），中央為白色卡片，顯示抽中的 Emoji 與文字，並帶有「再轉一次」按鈕。

6. 核心功能需求 (Functional Requirements)

  F1. 隨機抽取系統：點擊主按鈕後，程式需從目前的午餐陣列中，透過 Math.random() 隨機選出一個項目。
  
  F2. 動態清單渲染：網頁載入時，需自動讀取內建的午餐資料，並將其渲染成畫面上的標籤列表。
  
  F3. 自訂新增選項：
    
    使用者可輸入「午餐名稱」與「Emoji」（若未輸入 Emoji 則預設為 🍽️）。
    
    點擊「加進機器」後，新選項需即時推入（Push）陣列，並同步更新畫面上的清單列表。
    
    新增成功需有短暫的視覺回饋（按鈕變色並顯示「新增成功！」）。
    
    防呆機制：名稱若為空值則跳出警告（Alert），拒絕新增。
  
  F4. 狀態重置：抽獎結束後，可透過點擊「再轉一次」按鈕關閉結果視窗，並將所有動畫與按鈕狀態恢復至初始設定。

8. 互動與動畫流程 (UX & Animation Flow)

  觸發階段：點擊「轉動扭蛋！」按鈕。
  
  主按鈕立即鎖定（Disabled），防止重複點擊。
  
  小熊表情切換為「困惑/期待」（眼睛變成斜線）。
 
  運轉動畫 (持續 1 秒)：
      
      扭蛋機本體啟動 CSS Keyframes 的左右搖晃動畫（Shake）。
      
      機身旋鈕順時針旋轉 360 度。
  
      掉落動畫 (持續 0.5 秒)：搖晃停止，一顆扭蛋從機器底部出口垂直掉落。
  開獎階段：
    彈出全螢幕結果卡片，卡片帶有放大顯現（Scale）的轉場效果。
    顯示抽中的午餐名稱與對應圖示。
    小熊表情切換為「開心」（眼睛變成向上彎的半圓形）。
